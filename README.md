# DisplayCast 局域网播控软件

一款 **单 EXE、无客户端/服务端分离** 的 Windows 局域网显示设备播控软件。同一个安装包装在所有设备上，靠「角色」区分用途：

- **播放端**：显示设备上全屏无边框播放，默认开机自启、无人值守。
- **控制台**：在你的电脑上管理所有播放端，自动发现设备、编排节目、一键下发、实时预览。

## 技术栈

- .NET 10（LTS）+ WPF（Windows 专用、单 EXE 打包）
- 图片/视频播放：`MediaElement`（Windows 媒体基础，推荐 MP4/H.264）
- 网页播放：`WebView2`（依赖 WebView2 运行时，Win10/11 一般已内置）
- 实时预览：WPF 渲染管线抓屏 → JPEG 回传
- 通信：UDP 广播设备发现 + 自定义 TCP 帧协议（JSON + 二进制）
- 配置存储：JSON（`%APPDATA%\DisplayCast\`）
- 开机自启：注册表 `HKCU\...\Run` 项

## 网络端口

| 端口 | 协议 | 用途 |
|------|------|------|
| 8790 | TCP | 控制命令 / 素材上传 / 状态 / 预览 |
| 8791 | UDP | 控制台广播 DISCOVER（播放端监听） |
| 8792 | UDP | 播放端广播公告（控制台监听） |

> 端口分离（8791/8792）使同一台电脑可同时运行播放端与控制台，方便调试。

## 环境要求

- **Windows 10/11**
- **.NET 10 SDK**（下载：https://dotnet.microsoft.com/download/dotnet/10.0）

## 构建与运行

```bash
# 还原依赖并编译
dotnet build src/DisplayCast.App/DisplayCast.App.csproj

# 运行
dotnet run --project src/DisplayCast.App/DisplayCast.App.csproj

# 发布为单文件 EXE（自包含，免安装 .NET 运行时）
dotnet publish src/DisplayCast.App/DisplayCast.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

## 使用说明

1. **首次运行**：弹出角色引导，选择「播放端」或「控制台」，并确认开机自启。
2. **播放端**：全屏无边框自动轮播（图片/视频/网页）；本机可用 `--role=player` 覆盖角色。
3. **控制台**：
   - 「扫描设备」自动发现局域网播放端（也支持 15s 周期自动公告，打开即见）；
   - 「素材库」导入图片/视频、添加网页 URL；
   - 右侧编排「节目单」（排序/时长/顺序/随机），选中设备后「下发节目」一键推送（素材自动上传、增量更新）；
   - 设备列表实时显示缩略预览、在线状态、当前播放内容；
   - 支持给每台设备**添加/修改备注**（用于识别对应播放屏）；
   - 支持下一首/上一首/开屏关屏/音量/重启播放端/紧急插播/设备分组；
   - 「远程操作网页」可实时操作播放端正在显示的网页（点击关闭广告、输入登录、刷新/前进/后退、执行 JS）。
4. **命令行参数**：`--role=player` / `--role=console` 覆盖角色，便于批量部署。

## 功能清单

**播放端**：全屏无边框（可指定屏幕）· 图片/视频/网页混合轮播 · 顺序/随机 · 本地离线缓存续播 · 开机自启 · 实时预览抓屏回传 · 紧急消息插播 · 开关屏 · 音量 · 定时开关屏 · 崩溃自动重启

**控制台**：设备自动发现 · 实时缩略预览 · 素材库（图片/视频/网页）· 节目单编排 · 一键下发（增量上传）· 多节目单 · 远程控制 · 设备分组 · 设备备注 · 网页远程操作 · 密码锁定 · 开机自启开关

## 目录结构

```
DisplayCast/
├── DisplayCast.sln
└── src/DisplayCast.App/
    ├── App.xaml / App.xaml.cs        # 启动入口、角色路由、单实例、崩溃自恢复
    ├── Models/                        # 数据模型（配置、节目、素材、设备）
    ├── Net/                           # 协议（帧协议、消息类型）
    ├── Core/                          # 配置读写、开机自启、抓屏、JSON 存储
    ├── Player/                        # 播放端（播放引擎、TCP 服务、UDP 发现、紧急消息）
    ├── ConsoleUI/                     # 控制台界面（设备管理、素材、节目单、设置）
    └── Setup/                         # 首次运行角色引导
```
